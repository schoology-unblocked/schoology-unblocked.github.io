Accessibility Statement

Yohoho 77 aims to provide a browser game website that is simple to navigate, readable, and usable across modern devices.

Accessibility Efforts

We use clear navigation links, readable headings, responsive layouts, alt text where practical, and simple controls for game pages. We continue to improve page structure and usability over time.

Limitations

Some embedded third-party games may not fully support every accessibility feature. Yohoho 77 may not control the internal design of external game content.

Feedback

If you find an accessibility problem, contact ckaracar@gmail.com with the page URL and a description of the issue.
